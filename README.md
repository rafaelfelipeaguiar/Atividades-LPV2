# Atividades LPV II

Repositório para armazenar as atividades da disciplina **Linguagem de Programação Visual II**.

## Estrutura

Cada pasta representa uma atividade diferente:

- **Atividade01** - Projeto ASP.NET MVC inicial
- **Atividade02** - Validações avançadas com Data Annotations (Cliente Premium)

## Como usar

1. Navegue até a pasta da atividade desejada
2. Abra a solução `.sln` no Visual Studio ou Rider
3. Execute o projeto normalmente
